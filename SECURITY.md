# Security Policy

Defensive auditor — it reads an inventory file you provide and reports risk; it does not connect to
or probe devices. Use it only on inventories you own or are authorized to assess. A rule that
*misses* an outdated firmware or default credential (false clean) is the high-severity failure mode.

Report issues **in this tool** privately: GitHub **Report a vulnerability** on this repo, or email
the contact on the org profile. Target: **5 business days** to acknowledge, coordinated disclosure.
